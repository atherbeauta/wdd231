Individual Project Site Plan

WDD 231 – Web Frontend Development

Site Name

Kazadi Athanase Muamba – Web Developer Portfolio

This site name was chosen because it clearly represents a personal professional portfolio. It highlights my identity as a web developer and allows potential employers or clients to easily recognize the purpose of the website.

Optional domain: kazadi-dev.com

Site Purpose

The purpose of this website is to present my web development skills, projects, and contact information. The site will serve as an online portfolio showcasing completed projects, technical abilities, and a way for visitors to get in touch with me for job opportunities or collaborations.

Scenarios

  • What web development projects has Kazadi completed?
  • How can I contact Kazadi for a job or freelance opportunity?

Color Scheme

  • Dark Blue (#1e3a8a): Used for headings, header background, and accents.
  • Light Gray (#f3f4f6): Used for page background and section backgrounds.

Typography

  • Roboto (sans-serif): Used for headings and body text to ensure readability and a clean, modern look.
